# RabPDF Windows 1.5.5 and Android 0.5.9

- Added a small RabPDF logo immediately after the name in About.
- Reduced the Darjeeling headline size while keeping it prominent.
- Removed the country name and flag from app credits and translations.
- Existing document tools, scanner, purchases, and privacy behavior are unchanged.

## Uploads

- Microsoft Store: RabPDF-1.5.5.0-x64.msix (unsigned Store submission package).
- Google Play: RabPDF-Android-0.5.9-code14.aab.
- Direct Android installation: RabPDF-Android-0.5.9-code14.apk.
- Windows direct download: EXE or FastStart ZIP.

## Testing Limitations

The prior scanner emulator run showed a System UI not responding dialog. Real-phone scanner testing remains necessary. This UI-only update does not claim to resolve that issue. Microsoft Store approval is not guaranteed; the exact PDF from the prior failed compression review was unavailable for reproduction.
